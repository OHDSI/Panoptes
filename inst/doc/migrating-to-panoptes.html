Migrating copied database helpers to Panoptes

Move declaration parsing, environment policy, adapters, context assembly, resource lifecycle, and CI drift checks into Panoptes. Keep consumer fixtures, behavior, assertions, tables, and cleanup in the consuming package.

Core replacement

config <- Panoptes::readDatabaseTestConfig(package = "CohortGenerator")
Panoptes::skipIfNoLiveDatabase(config)
Panoptes::withDatabaseTestContext(
  config,
  legacyAliases = cohortGeneratorAliases,
  verify = TRUE,
  {
    # Existing consumer behavior and on.exit() cleanup.
  }
)

Remove environmentPrefix, add executable runner and OS fields, map secrets to normalized HADES_* names, keep one complete pull-request/manual matrix, and validate it against the declaration.
