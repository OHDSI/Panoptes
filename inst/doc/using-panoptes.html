Using Panoptes in a HADES package

Panoptes owns live-database test infrastructure. The consuming package owns its declaration, fixtures, behavior, assertions, and database-object cleanup.

Execution contract

  1. Read and fully validate the package declaration.
  2. Select one DBMS and enforce enabled, required, runner, and OS policy.
  3. Resolve normalized environment variables and explicit legacy aliases.
  4. Validate values before creating credentials or connection details.
  5. Create a scoped context and run package-owned behavior.

Basic test

config <- Panoptes::readDatabaseTestConfig(package = "MyHadesPackage")
Panoptes::skipIfNoLiveDatabase(config)
Panoptes::withDatabaseTestContext(config, verify = TRUE, {
  connection <- DatabaseConnector::connect(context$connectionDetails)
  on.exit(DatabaseConnector::disconnect(connection), add = TRUE)
  # Run package behavior and assertions.
  Panoptes::requireDatabaseTestConnectionAttempted(context)
})
