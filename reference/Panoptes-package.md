# Panoptes: Database Platform Compatibility for HADES

Panoptes helps HADES package maintainers explicitly declare and verify
support for database platforms. It standardizes the infrastructure
around live database behavior tests while consuming packages retain
their own fixtures, assertions, and cleanup.
